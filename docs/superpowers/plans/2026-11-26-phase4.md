# Phase 4 Implementation Plan

**Spec:** ../specs/2026-11-26-phase4-design.md (approved by user).

**Goal:** Add learned manager/worker, goal helpers, optional RND and RGB exit supervision to the existing PPO pipeline.

**Architecture:** Keep legacy forward/checkpoint behavior when switches are off. A separate hierarchical forward returns stored-goal-conditioned worker logits and manager heads. Rollouts record goal boundaries; manager updates use interval returns. Training-only curiosity and exit labels never enter actor inputs.

**Constraints:** No scripted goal choices or fabricated labels/results. Five goals, eight-decision default cadence. Preserve local setup edits. PR targets original upstream main; only feature branch may be pushed.

## Tasks and interfaces

- [x] Hierarchy/RGB: add config flags, RGB feature extraction and CNN, neural goal heads/embedding and explicit hierarchy state in submission; test cadence, replay, conditioning, legacy compatibility and gradient paths first.
- [x] RND (independent module): `training/rnd.py`, `RND(input_dim, device='cpu', ...).bonus(features, update_stats=True)`, `.update(features)` and `.state_dict()/load_state_dict()`. Legal flat feature vectors only; normalize using past statistics, frozen target, checkpoint optimizer and moments. Own tests demonstrate novelty reduction and state restoration using real observations.
- [x] Visibility (independent module): `training/exit_visibility.py`, `ExitVisibility.from_env(env).label()` returns `(float_target, bool_known)` from actual generated-map exit geometry and live camera/depth occlusion. Unsupported layouts masked. Own real-engine tests cover visible/hidden/behind-camera maps. No edits to official wrapper/map generator.
- [x] Training integration: goal helper reward decomposition, rollout labels/goal handoff, recurrent PPO boundary losses, RGB auxiliary loss and RND, CLI/config/resume support. Tests for interval returns, boundary masks, invalid configs, checkpoint resume and real-engine all-feature training.
- [ ] Verification: real training smoke/checkpoint play, broad regressions, validator/latency, independent review. Document actual measurements and limitations; commit feature files only; push feature branch and create described upstream PR.
